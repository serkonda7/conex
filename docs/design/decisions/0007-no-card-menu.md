# 0007: No ⋯ menu on integration cards
- Date: 2026-11-19
- Status: accepted (replaces the card ⋯ menu of 0005 and 0006)

Integration cards no longer have a ⋯ menu, in either the grid or the list
layout. A card keeps only its name and description, status pills, sync detail
and a footer with a link and one action. Settings and "Force full sync" are
reached from the integration's detail page (0006), which keeps its own header
menu; the footer "Fix connection →" link still goes to the Settings tab.

Removing the menu leaves more room for the card title and description, which
wrap less often now that the cards are wider.
